# ระบบเติมเหรียญ + Admin

เพิ่มเฉพาะระบบเติมเหรียญ โดยไม่รื้อ UI/โมเดล/ระบบกล่องเดิม

## สิ่งที่เพิ่ม
- ปุ่ม `เติมเหรียญ` อยู่ข้างยอดเหรียญด้านบน
- เอาปุ่ม `+` มุมขวาบนออก
- เอาปุ่ม `+ เติมแต้ม` ด้านซ้ายออก
- เอาเมนู `เติมแต้ม` ด้านซ้ายออก
- ซองของขวัญ / Wallet: กรอกจำนวนเอง ขั้นต่ำ 10 บาท + วางลิงก์
- TrueMoney Cash Card: 50 / 90 / 150 / 300 / 500 / 1,000 บาท + รหัส 14 หลัก + แนบรูป
- คำขอถูกส่งเข้า Supabase และรอแอดมิน
- Admin ตรวจลิงก์/รูป/รหัส แล้วกดอนุมัติ
- เมื่ออนุมัติ ระบบเพิ่มเหรียญฝั่งผู้เล่นจาก Database และหน้าเกมจะอัปเดตอัตโนมัติ
- Admin Panel แยกที่ `admin.html`

## ตั้งค่า Supabase
1. รัน `supabase-setup.sql` ของโปรเจกต์เดิมให้เรียบร้อย
2. รัน `topup-setup.sql` ใน Supabase SQL Editor
3. เปิด Authentication แล้วสร้างบัญชีอีเมลสำหรับแอดมิน 1 บัญชี
4. ไปที่ Authentication → Users → คัดลอก UUID ของบัญชีแอดมิน
5. รัน SQL นี้ โดยแทน UUID:

```sql
insert into public.admin_users(user_id)
values ('ใส่-UUID-บัญชี-แอดมิน-ตรงนี้')
on conflict (user_id) do nothing;
```

6. เปิด `https://โดเมนของคุณ/admin.html`
7. ล็อกอินด้วยอีเมล/รหัสผ่านแอดมิน

## ขั้นตอนอนุมัติ
- Wallet: กด `คัดลอกลิงก์` → ตรวจสอบยอดเงินจริงใน Wallet → กด `อนุมัติและเพิ่มเหรียญ`
- Card: ตรวจรหัส 14 หลัก + รูปหลักฐาน → ตรวจสอบการใช้งาน/ยอดของบัตรตามช่องทางที่คุณใช้ตรวจ → กดอนุมัติ
- ระบบจะเพิ่มเหรียญเพียงครั้งเดียว เพราะคำขอที่ไม่ใช่ `pending` จะอนุมัติซ้ำไม่ได้

## หมายเหตุสำคัญ
ระบบนี้เป็นระบบตรวจสอบด้วยแอดมิน ไม่ได้เชื่อม API ของ TrueMoney เพื่อยืนยันยอดโดยอัตโนมัติ
ห้ามใส่ Supabase `service_role`/Secret key ในเว็บ
