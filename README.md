# Mystery Box Web 3D — Supabase Online Ready

เวอร์ชันนี้ยังคงระบบเกมเดิมทั้งหมด และเพิ่ม "ชั้นเชื่อมต่อออนไลน์" สำหรับ Supabase โดยไม่ลบระบบเดิม

## ตอนนี้เพิ่มอะไรแล้ว
- เพิ่ม `supabase-config.js` สำหรับใส่ Project URL และ Publishable/anon key
- เพิ่ม `online.js` สำหรับเชื่อม Supabase
- ถ้าตั้งค่า Supabase แล้ว ระบบจะสร้าง/โหลดผู้เล่นออนไลน์แบบ Anonymous ชั่วคราว
- เหรียญจะซิงก์ไป `profiles.coins`
- ประวัติการสุ่มจะซิงก์ไป `gacha_history`
- ประวัติที่ดึงจากออนไลน์ย้อนหลัง 7 วัน
- ถ้ายังไม่ได้ตั้งค่า Supabase เว็บยังเปิดแบบเดิมได้ ไม่ทำให้ Prototype เดิมหยุดทำงาน

## สำคัญมาก
อย่าใส่ `service_role` หรือ Secret key ในเว็บเด็ดขาด
ใช้เฉพาะ Project URL + Publishable/anon key เท่านั้น

## ขั้นตอนสำหรับมือใหม่

### 1. สร้าง Supabase Project
เข้า Supabase แล้วกด New project
- ตั้งชื่อโปรเจกต์ เช่น `mystery-box`
- ตั้ง Database Password แล้วเก็บไว้
- รอให้โปรเจกต์สร้างเสร็จ

### 2. เปิด Anonymous Sign-ins
ไปที่:
Authentication → Sign In / Providers → Anonymous Sign-Ins
แล้วเปิดใช้งาน

### 3. สร้างตาราง
ไปที่ SQL Editor แล้วรัน SQL นี้:

```sql
create table public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  username text not null,
  coins bigint not null default 24,
  created_at timestamptz not null default now()
);

create table public.gacha_history (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  prize_name text not null,
  rarity text not null,
  icon text,
  box_name text not null,
  created_at timestamptz not null default now()
);

create index gacha_history_user_created_idx
on public.gacha_history(user_id, created_at desc);

alter table public.profiles enable row level security;
alter table public.gacha_history enable row level security;

create policy "users can read own profile"
on public.profiles for select
to authenticated
using (auth.uid() = id);

create policy "users can insert own profile"
on public.profiles for insert
to authenticated
with check (auth.uid() = id);

create policy "users can update own profile"
on public.profiles for update
to authenticated
using (auth.uid() = id)
with check (auth.uid() = id);

create policy "users can read own history"
on public.gacha_history for select
to authenticated
using (auth.uid() = user_id);

create policy "users can insert own history"
on public.gacha_history for insert
to authenticated
with check (auth.uid() = user_id);
```

### 4. ใส่ Project URL และ key
ไปที่:
Project Settings → API

คัดลอก:
- Project URL
- Publishable key (หรือ anon key ถ้า Dashboard ของคุณแสดงชื่อนี้)

เปิด `supabase-config.js` แล้วใส่ค่า:

```js
export const SUPABASE_URL = '...';
export const SUPABASE_ANON_KEY = '...';
```

ห้ามใช้ service_role/secret key

### 5. ทดสอบใน VS Code
เปิดด้วย Live Server หรือเว็บเซิร์ฟเวอร์ที่รองรับ ES Modules

เปิด DevTools → Console
ถ้าเชื่อมต่อสำเร็จ จะไม่มี error เรื่อง Supabase และจะมีข้อมูลผู้ใช้ใน:
Supabase → Authentication → Users

จากนั้นตรวจ:
Supabase → Table Editor → profiles
Supabase → Table Editor → gacha_history

## สิ่งที่ยังต้องทำในขั้นต่อไป
ตอนนี้เป็น "Online Foundation" ยังไม่ใช่ระบบเงินจริง/ระบบสมาชิกเต็มรูปแบบ

ขั้นต่อไปควรทำทีละระบบ:
1. ระบบสมัคร/เข้าสู่ระบบจริง
2. โปรไฟล์ผู้ใช้
3. Inventory ออนไลน์
4. ระบบสุ่มฝั่ง Server เพื่อกันโกง
5. ระบบเติมเงินออนไลน์ + คำขอเติมเงิน
6. Admin Panel + สิทธิ์ admin
7. Realtime
8. Deploy ขึ้นเว็บจริง

**อย่าเพิ่งเอาระบบเติมเงินจริงไปใช้จริงก่อนทำข้อ 4–6** เพราะยอดเหรียญและการอนุมัติเติมเงินต้องทำฝั่ง Server/Database ที่เชื่อถือได้ ไม่ควรให้ Browser เป็นคนเพิ่มยอดเอง
